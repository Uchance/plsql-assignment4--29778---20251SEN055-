About the project



Student Registration and Grading Management System






For this assignment, I recommend developing a Student Registration and Grading Management System using Oracle Database and PL/SQL.

This is a practical institutional application that can be used by a university to manage student information, courses, registrations, and academic results.

The system will demonstrate all the required PL/SQL concepts:
- Records (user-defined records and %ROWTYPE).
- Collections (associative arrays and nested tables).
- Implicit cursors.
- Explicit cursors.
- Bulk processing (BULK COLLECT and FORALL).
- Stored procedures and functions.
- Predefined and user-defined exception handling.



2. System objectives
The application will allow the university to:
1. Register new students.
2. Create and manage academic courses.
3. Enroll students in courses.
4. Record and update student grades.
5. Display students enrolled in particular courses.
6. Calculate students' average grades.
7. Process multiple student registrations efficiently.
8. Apply grade adjustments to multiple students using bulk processing.
